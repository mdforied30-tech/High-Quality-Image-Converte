# High Quality Image Convert

By FM Developer. Static site: no server needed, all processing runs in the browser.

## Features
- JPG to JPEG, PNG to JPG, JPG to PNG, any to WebP, WebP to JPG (quality up to 100%)
- PNG/JPG to SVG and EPS (colour vector tracing)
- AI Upscale 2x/3x/4x (ESRGAN) with Fast Upscale fallback
- Colour enhance (Natural, Vivid, Rich), batch files, ZIP download

## Deploy
1. Create a GitHub repo, upload: index.html, style.css, app.js, netlify.toml, README.md
2. Netlify > Add new site > Import from GitHub > pick repo > Deploy (build command empty, publish directory `.`)
